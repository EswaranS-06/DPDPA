# Section 4 - Grounds for processing personal data

Chapter II: Obligations of Data Fiduciary | **Phase 3** (not yet in force - 2027-05-13)

## Summary
Process only for a lawful purpose: (a) with consent, or (b) for certain legitimate uses (s.7).

## Atomic obligations
- [[OBL-GOV-05]] Lawful purpose only
- [[OBL-LB-01]] Specified purpose defined per activity
