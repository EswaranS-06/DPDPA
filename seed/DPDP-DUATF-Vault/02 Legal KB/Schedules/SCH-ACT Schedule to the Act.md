# Schedule to the Act - Penalties

**Phase 3** (not yet in force - 2027-05-13)

Penalty caps: (1) s.8(5) security Rs 250 cr; (2) s.8(6) breach intimation Rs 200 cr; (3) s.9 children Rs 200 cr; (4) s.10 SDF Rs 150 cr; (5) s.15 DP duties Rs 10,000; (6) s.32 voluntary undertaking - up to the amount for the underlying breach; (7) any other provision Rs 50 cr.

| Item | Breach | Maximum penalty |
|---|---|---|
| P1 | s.8(5) security safeguards | s.8(5) security safeguards - up to Rs 250 crore |
| P2 | s.8(6) breach intimation | s.8(6) breach intimation - up to Rs 200 crore |
| P3 | s.9 children | s.9 children - up to Rs 200 crore |
| P4 | s.10 SDF | s.10 SDF - up to Rs 150 crore |
| P5 | s.15 Data Principal duties | s.15 Data Principal duties - up to Rs 10,000 |
| P6 | s.32 voluntary undertaking | s.32 voluntary undertaking |
| P7 | any other provision | any other provision - up to Rs 50 crore |
