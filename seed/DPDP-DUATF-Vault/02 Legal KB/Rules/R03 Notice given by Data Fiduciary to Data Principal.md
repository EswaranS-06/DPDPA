# Rule 3 - Notice given by Data Fiduciary to Data Principal

**Phase 3** (not yet in force - 2027-05-13) | G.S.R. 846(E)

## Summary
(a) standalone and understandable independently; (b) clear plain language, itemised description of personal data and specified purpose(s) with description of goods/services/uses; (c) communication link / means to withdraw consent (comparable ease), exercise rights and complain to Board.
