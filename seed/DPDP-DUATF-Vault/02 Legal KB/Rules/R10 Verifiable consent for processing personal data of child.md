# Rule 10 - Verifiable consent for processing personal data of child

**Phase 3** (not yet in force - 2027-05-13) | G.S.R. 846(E)

## Summary
Due diligence that parent is identifiable adult via reliable details already held, voluntarily provided details, or virtual token from authorised entity (incl. DigiLocker).
