# Risk Scales



| Score | Label | Meaning |
|---|---|---|
| L1 | Rare | Would require unusual circumstances |
| L2 | Unlikely | Control mostly works; few exposures |
| L3 | Possible | Gap known; exposure moderate |
| L4 | Likely | Gap systemic; many DPs/transactions exposed |
| L5 | Almost certain | Non-compliance occurring now at scale / visible to DPs |
| I1 | Minimal | Penalty tier none/admin; few DPs; no sensitive context |
| I2 | Minor | Rs 50 cr tier; limited DPs; low sensitivity |
| I3 | Moderate | Rs 50 cr tier at scale OR sensitive context |
| I4 | Major | Rs 150-200 cr tier (SDF, children, breach intimation) OR health/financial/biometric at scale |
| I5 | Severe | Rs 250 cr tier (security) OR children + sensitive + scale OR regulator/public exposure |
| 1-4 | Low | band |
| 5-9 | Medium | band |
| 10-16 | High | band |
| 17-25 | Critical | band |
