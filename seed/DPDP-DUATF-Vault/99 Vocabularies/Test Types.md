# Test Types



| Test | Use |
|---|---|
| Inquiry | Interview control owner - lowest assurance, never alone |
| Inspection | Examine documents, configs, records |
| Observation | Watch the control operate (e.g. front-desk collection) |
| Re-performance | Independently execute (e.g. submit a rights request, withdraw consent) |
| Technical test | Scan/config review/network capture (e.g. SDK traffic, encryption) |
| Data analytics | Full-population test (e.g. records past retention, consent without notice version) |
